# Kitchen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the factory so it cooks one course per day: a private Vercel deployment, a Blender-polished trailer of the core workflow on real data, a score, and Taste/Keep/Go buttons in Discord.

**Architecture:** No new system. A daily `scripts/kitchen-daily.sh` picks the queued idea and launches the existing factory with `KITCHEN=1`. `triggers/factory.md` grows four stations after its done step (web shell, deploy, trailer, score), then serves the course to Discord. The course repo gets two GitHub Actions workflows (verify and design-pass) copied from `kitchen/workflows/`. Scores live in a new `course_scores` Mongo collection, keyed by date.

**Tech Stack:** Bun + TypeScript (`bun test`), MongoDB, discord.js 14, Vercel plugin (MCP), Playwright, Blender 4.x headless (`blender -b -P`), ffmpeg, `anthropics/claude-code-action`.

**Spec:** `docs/superpowers/specs/2026-11-12-kitchen-design.md`

## Global Constraints

- One course per day, max. Never lower the triage bar to fill a day; a day with no queued idea is a recorded skip.
- Courses using our data: Vercel Deployment Protection ON, trailer never posted outside the private Discord guild.
- Data mix target: ~80% our data / ~20% public no-login data; any mocked data in the core workflow → `real_data = 0`.
- House style: bright solar-punk, retro-gamer (saturated greens + golds, pixel accents, chunky type, CRT glow).
- Trailer length 30–90 s, at `demo/trailer.mp4` in the course repo.
- Design pass: ≤ 3 passes, stop early when the style score does not improve.
- Course wall-clock cap: 90 min when `KITCHEN=1` (the factory's 30 min stays for `/build`). Round cap 20 unchanged.
- Deploy only through the Vercel plugin; the `vercel*` CLI deny-list stays.
- Budget: Max plan (local `claude`, Actions via `CLAUDE_CODE_OAUTH_TOKEN`). Blender renders locally, never on Actions.
- Tests: `bun test` (this repo's runner). No Claude co-author trailer on commits.

## Review Focus

1. **Protected preview blocks the robots.** Playwright (Actions and the trailer recorder) gets the Vercel login wall. Expected: both send `x-vercel-protection-bypass`, and Verify fails loudly (not "passes" on the login page) if the bypass is missing. Pinned in Task 6 (assert the page is not the Vercel login).
2. **Stale or double button taps.** Go is tapped twice, or on an old course. Expected: the verdict is idempotent, and the second Go replies "already promoted" without redeploying. Pinned in Task 4.
3. **Blender or ffmpeg missing or failing.** Expected: the course is still served (it works), with `polish = 0` and a note "trailer failed: <reason>". Never a silent missing video. Pinned in Task 7.
4. **Queue empty or already cooked today.** Expected: a skip is recorded once, and a second run the same day is a no-op. Pinned in Task 3 + Task 8.
5. **Verify red.** Expected: no trailer, no serve, the idea is parked with learnings, and `course_scores.works = false`. Pinned in Task 5 (trigger text) + Task 2 (doc builder).
