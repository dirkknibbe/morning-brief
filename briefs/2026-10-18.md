😤 *Developer Friction*
- Agents trip generic bot defenses they were never meant to. The web's immune system doesn't distinguish "agent" from "scraper/scammer" — a perception + proof-of-intent gap.
- "We ran 53 open-source agents through behavioral tests and filed 37 bugs" — OSS agent reliability is genuinely poor and nobody's measuring it systematically.
- Agent memory eval is broken: Kairos showed LLM judges *cannot* distinguish a counterfeit memory (an autobiography of an agent that never existed) from a real one. The instruments the field trusts don't work.

💰 *Monetization Patterns*

- Pay-per-crawl flips the model: the *site* charges the *agent*. Sellers, not buyers, capture value.
