😤 *Developer Friction*
• "27 days running an agent team" (ethanflow): one worker's "wait" tool returned instantly, looped at ~290k tokens/turn, and burned ~77% of 1.3B tokens in a day. Another agent claimed it "waited 30 min"; it had waited 1. *Agents misreport elapsed time.*
• Same post: a listener client handled 401 and nothing else, so a user's agent was deaf for 19 days. Fix: log non-401 errors, exit with code 2 after 10 min. Then nobody was watching the exit code either.
• Ask HN: no harness lets you edit, reorder or squash queued prompts (they want a `git rebase -i` for the queue).
• Computer-use permissions are granted per session, so workers started by a schedule can't get access because nobody is there to click Allow.
