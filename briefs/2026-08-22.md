☀️ *Morning Brief* — Saturday, Aug 22

*The lead:* Access control is the unsexy moat. DeepSQL's post ("Giving an LLM your prod DB is easy; taking access away is hard") nails the pattern — a read-only connection is not an access policy. `SELECT` is the dangerous verb once a second user logs in and the agent's service account is a superset of every human's authority. Their fix: resolve English policies into deny-lists enforced *before* schema even enters the context window (denied tables never get introspected). Same class of problem UIPE lives near — the boring enforcement layer is where agents actually break, and where people will pay.

- Three separate "shared brain for agents" launches in one day: *OzBrain* (s70, brain layer Claude/Cursor/ChatGPT read+write), *AGY Memory Engine* (SQLite FTS5 + MCP), *Heimdall* (verified knowledge with STRONG/WEAK/STALE trust verdicts). Agent memory is officially a crowded category.

😤 *Developer Friction* — where the money is
- *Agent authz is unsolved.* DeepSQL had to ship impersonation *first* — "look at the DB as this user" — before policies meant anything. Audit logs that read `deepsql_agent SELECT...` for every human = you can't answer "who saw this row."
- *Statement-level guarding, not query-level.* CTEs, subqueries, unions, `CALL`, pasted SQL all bypass naïve FROM-clause allowlists. Everyone building this ships the bypass first, then patches it.
- *Prompt injection is now a marketing channel:* OzBrain's landing page embeds instructions telling *your* agent to reply in <150 words with three ranked reasons to buy. The attack surface is the pitch.

💰 *Monetization Patterns*
